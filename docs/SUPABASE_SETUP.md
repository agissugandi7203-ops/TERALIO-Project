# Panduan Setup Supabase

Dokumen ini memandu langkah demi langkah untuk mengintegrasikan database Supabase ke dalam project.

---

## 1. Buat Project Baru di Supabase
1. Kunjungi [supabase.com](https://supabase.com) dan masuk ke akun Anda.
2. Klik tombol **New Project**.
3. Masukkan nama project, password database, dan pilih region terdekat (misal: Singapore).

---

## 2. Dapatkan Kredensial API
1. Buka dashboard project Supabase Anda.
2. Masuk ke menu **Project Settings** (ikon gerigi) -> **API**.
3. Salin nilai berikut:
   - **Project URL** (contoh: `https://xyzcompany.supabase.co`)
   - **anon / public key** (untuk Frontend dan Backend)
   - **service_role secret key** (hanya untuk Backend, jangan pernah dipasang di Frontend!)

---

## 3. Jalankan SQL Schema di Supabase SQL Editor
Buka menu **SQL Editor** pada dashboard Supabase, lalu jalankan query SQL berikut untuk membuat tabel `items`:

```sql
-- Buat tabel items
CREATE TABLE IF NOT EXISTS public.items (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title VARCHAR(100) NOT NULL,
    description TEXT,
    category VARCHAR(50) DEFAULT 'General',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Aktifkan Row Level Security (RLS)
ALTER TABLE public.items ENABLE ROW LEVEL SECURITY;

-- Berikan izin SELECT (read) untuk semua user (termasuk anonim)
CREATE POLICY "Allow public read access"
ON public.items FOR SELECT
TO anon, authenticated
USING (true);

-- Berikan izin INSERT untuk user yang sudah login atau dengan service_role
CREATE POLICY "Allow insert access"
ON public.items FOR INSERT
TO anon, authenticated, service_role
WITH CHECK (true);

-- Masukkan data awal (seed)
INSERT INTO public.items (title, description, category) VALUES
('Inisialisasi Project Frontend (Vite)', 'Setup struktur folder frontend dengan komponen React dan Vite bundler.', 'Frontend'),
('Inisialisasi Backend (Express)', 'Setup Express server modular dengan routing, services, dan models.', 'Backend'),
('Koneksi Supabase', 'Konfigurasi client Supabase pada frontend dan backend dengan credential check.', 'Database');
```

---

## 4. Konfigurasi Environment Variables

### Pada Frontend (`frontend/.env`)
```env
VITE_SUPABASE_URL=https://your-project-id.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-public-key
VITE_API_URL=http://localhost:5000
```

### Pada Backend (`backend/.env`)
```env
PORT=5000
NODE_ENV=development
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_ANON_KEY=your-anon-public-key
SUPABASE_SERVICE_ROLE_KEY=your-service-role-secret-key
```
